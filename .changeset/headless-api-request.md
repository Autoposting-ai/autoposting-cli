Add `ap api <METHOD> <path>` to call any REST route on the server allow-list (`--list` shows them), and five local `ap mcp` tools: `api-request`, `list-api-routes`, `upload-media` (local image or video for posts), `upload-clip` (local video for AI clipping) and `publish-clip`. The allow-list comes from the hosted server, and both refuse every route if it cannot be loaded.
